В архиве готовый сайт кадрового агентства и проект для редактирования в Codex. Чтобы посмотреть сайт без установки программ, откройте файл «ИП Кириллов Сергей Евгеньевич — картотека.html» в браузере. Чтобы разместить сайт на домене, используйте папку `dist/`. Она содержит все восемь страниц, изображения, шрифты и стили.

## Публикация готовой сборки

1. Создайте на хостинге статический сайт. Если панель предлагает выбрать папку публикации, укажите `dist`. При загрузке через файловый менеджер или SFTP перенесите **содержимое** `dist/` в корневую веб-папку домена. Файл `index.html` и каталоги `_astro/`, `fonts/`, `images/` должны лежать прямо в ней.
2. Включите выдачу `index.html` из вложенных каталогов. У каждой страницы есть свой файл. Если у хостинга есть режим SPA с перенаправлением всех путей на главную, оставьте его выключенным.
3. Откройте технический адрес хостинга. Перейдите напрямую на `/about/`, `/employers/` и `/personal-data/`, затем обновите страницу. У каждого адреса должен открываться свой заголовок, с оформлением и изображениями. Публичная конфигурация работает с электронной почтой и телефоном. База данных, сервер приложений и переменные окружения для неё не требуются.

## Домен и HTTPS

1. В панели хостинга добавьте точное имя домена к этому сайту. Если планируется адрес с `www`, добавьте и его. Скопируйте значения записей, которые выдаст хостинг для каждого имени. Значения зависят от провайдера и созданного сайта.
2. В панели, обслуживающей DNS-зону, укажите выданные значения. Для корня домена панель обычно показывает имя `@` или пустое поле. Хостинг может выдать адрес IPv4 для записи A, IPv6 для AAAA, имя для CNAME поддомена или отдельную запись подтверждения. Обновите относящиеся к сайту записи. Сохраните MX и записи для работы почты, включая SPF, DKIM и DMARC. [Пример настройки записей у DNS-провайдера](https://timeweb.cloud/docs/domains/dns-records-management)
3. Когда хостинг подтвердит домен, включите или дождитесь выпуска сертификата на каждое подключённое имя. Проверьте сайт по HTTPS. После этого включите перенаправление с HTTP и, если используется два имени, перенаправление со второго на основное с сохранением пути. [Пример подключения домена и сертификата в панели хостинга](https://timeweb.cloud/docs/apps/domain)

## Как изменить сайт и пересобрать

Откройте в Codex папку с `package.json`. Интерфейс построен на Astro, React и Tailwind CSS. Страницы находятся в `src/pages/`, компоненты в `src/components/`, контакты и реквизиты в `src/config/agency.json`. Иллюстрации и локальные шрифты находятся в `public/`.

Для сборки используйте Node.js с npm. Версия, на которой проверялся этот выпуск, — Node.js 26.4.0 с npm 11.17.0. Из корня проекта выполните команды по порядку в обычном окружении, где переменная `AGENCY_LOCAL_DEMO` не задана.

```sh
npm ci
npm run build
```

На хостинге со сборкой из Git корень проекта — папка с `package.json`, команда сборки — `npm run build`, выходной каталог — `dist`. Менеджер зависимостей использует `package-lock.json`. Локально команда `npm run preview` показывает результат сборки по адресу из терминала. Команда `npm run export:html` обновляет и сборку, и автономный HTML для пересылки.

Каталог `demo/` содержит инструменты разработчика для локальной проверки с вымышленными анкетами. Публичный сайт в `dist/` использует только формы подготовки письма и контактный телефон. Размещайте на хостинге только файлы из `dist/`.
