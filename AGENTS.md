# Работа с проектом

Инструкции по публикации и подключению домена приведены в README.md. Готовая публичная версия находится в dist/. Проект рассчитан на размещение в корне домена. Контакты и реквизиты хранятся в src/config/agency.json. Сохраните ведущий ноль ИНН.

Для интерфейса используйте React и Tailwind CSS, существующие компоненты и семантические токены проекта. Для задач дизайна используйте доступные Product Design и emil-design-eng. Для подходящих задач используйте Creative Production при его наличии, а для кинематографичных анимированных сайтов — animated-site. Если Creative Production недоступен, сообщите об этом и продолжайте доступными средствами.

Сохраняйте индивидуальный стиль бренда. Избегайте случайных градиентов, свечения и лишнего декора. Используйте короткие переходы для обратной связи и учитывайте prefers-reduced-motion. Пишите подписи секций обычным регистром с естественными интервалами. Выносите в компоненты повторяющиеся элементы и блоки, поддерживайте их применимые состояния и видимый фокус клавиатуры.
